`durable.new` asks name, project (a folder, or a URL to clone) and "not a git project", then runs `space new`; `durable.forget` drops a space's record; `durable.list` shows the recorded spaces with the guard's last line for each, read only.
It shells out to `space new|list|forget` (and `guard --dry-run`), and `space-path.mjs` is what picks the file: on a Windows home the `.cmd` in `%USERPROFILE%\.local\bin` when it is really there, otherwise the POSIX wrapper under `~/.pi/bin`, and one refusal naming both paths when neither is. Windows cannot exec the extensionless bash wrapper — that is the `os error 193` Create used to die with. The argv comes from `argv.mjs` and nowhere else, and nothing is created until Create.
Forgetting keeps the folder and its work on disk: the space simply stops being reopened, and nothing here closes a space, closes a tab, or deletes a file.
Open it with `alt-shift-d` or `alt-shift-n` (merge `keys.json` beside this file into `~/.config/herdr-app/keys.json`) or without any keys: `herdr-app do mod.open --name durable`.

That file's `global` section holds the key a fresh install also gets: `alt-shift-n` is `mod.open` with `{ "name": "durable" }` — the same overlay `alt-shift-d` opens, so the form arrives with its fields, its inline refusals and the clone toggle, on all three platforms. It used to be `terminal.open` running `space new`, which asked the questions in a terminal and had to carry the path of the installed `space` in its argv; that path is the one Windows could not start, and `mod.open` needs no argv at all. `install.mjs` merges the key into an existing `keys.json` (and moves an older `terminal.open` value to the form), and `keys.mjs` is the single place the binding is built.

`mod:durable` keeps its own `alt-shift-n` = `durable.new` on purpose: pressed inside the open overlay, a mod key is the one that answers, so `alt-shift-n` fills the New form instead of re-opening the overlay it is already in — a second press would drop a half-typed name. The global key opens the form; the mod key fills it.
